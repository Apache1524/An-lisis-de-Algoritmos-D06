# ReadMe de Act. Visualizador de Métodos de Ordenamiento

El código presenta una interfaz de usuario que permite generar listas de números aleatorios y visualizar el funcionamiento de cuatro algoritmos de ordenamiento: **Selection Sort**, **Merge Sort**, **Bubble Sort** y **Quick Sort**. La lista puede configurarse con un tamaño personalizado mediante el campo **N barras**. Cada algoritmo se ejecuta mostrando paso a paso cómo se acomodan las barras en la pantalla, usando animaciones para resaltar los elementos activos durante el ordenamiento. Además, el programa registra el tiempo aproximado de ejecución de cada método y permite observar comparaciones gráficas de rendimiento mediante **matplotlib**.

## Requisitos
- **Python 3.x**

## Librerías externas usadas
- **Tkinter**: librería estándar de Python para la creación de interfaces gráficas.  
- **matplotlib**: librería para la creación de gráficas, utilizada para mostrar comparativas de tiempos de ejecución entre los algoritmos.
